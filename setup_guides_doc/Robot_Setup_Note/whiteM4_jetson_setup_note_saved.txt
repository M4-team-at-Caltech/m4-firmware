white_m4 setup guide
This repo contain white_m4 ROS1 firmware

assume you have already complete assamble your new m4

Setup Jetson
1. clone this repo to the Jetson（Jetson/Jetson-ARK/holybro） on your m4
git clone --recursive git@github.com:Taoran2023/m4-firmware.git

2. build docker environment
cd m4-firmware
./build_docker.sh

3. USB rules
cd setup_scriptes
check 11-local.rules and change according to your own jetson board.
./set_udev_rules

Note: DO NOT run docker or test any function before complete following steps


Config Dynamixel Servos and RC-receive
1. use dynamixel Wizard config all servo assign ids 
disconnect U2D2 from Jetson and connect to a laptop

on jetson:
cd m4-firmware/m4_home/m4_ws/src/m4_base/config
*do not change motor_config.yaml if you also use XM540-W270-R servo, otherwise following official guide to change.
*change rc_channel_config.yaml following your own preferance, and change rc define also in PX4 QGround_Control
robot_config.yaml shows an example of servo configuration.

on laptop:
use dynamixel Wizard to config servos:
following [joints:] in robot_config.yaml file to assign id to servo
[1, 2, 3, 4, 5, 6, 7, 8]: transform joints
[9, 10, 11, 12]: wheel joints
use dynamixel wizard to move servo, find moving limit[zero_tick,min_tick,max_tick] of all transform joint and change parameters in robot_config.yaml. 
min_tick and zero_tick should be the encoder reading on wizard while robot in stand configuration.
set wheel joiints to velocity control mode



Setup flight computer
m4 use PX4 as flight control software. follow PX4_Setup_Note for more details.


verify setups:

1. check incomming RC reading and mavros setting
cd m4-firmware
./run_docker
access into container
cd m4_ws
source devel/setup.bash
roslaunch roslaunch m4_base interfaces.launch
use ros topic list and echo check rc channal setting also adjust parameters in rc_channel_config.yaml if you need

2. check servo setting
Note: you should use teser lift the robot during this test !!!

cd m4-firmware
./new_docker_terminal.sh
access into container
cd m4_ws
source devel/setup.bash
roslaunch m4_base m4_control.launch
you should see robot transform into stand mode, otherwise go back to Config Dynamixel Servos step and change servo setting

3. full pipline
if all test above passed, place robot on the ground with crouch2 configuration(fully expand all leg, wheel perpendicular to ground)

shutdown container
cd m4-firmware
./shutdown
or you can reboot

./startup.sh
after it finished the robot should become fully operational, you chould use RC to test functions.

4. Start up service
check start_up_note.txt for more details


now you after you reboot robot, robot should fully boot up on its own.
(it takes about 2min for white_m4 to fully bootup due to jetsson boot up time)
